# Docker Development Environment

This document describes the Docker-based development environment for MoneyCast.

## Prerequisites

- Docker & Docker Compose
- macOS/Linux (Windows requires WSL2)

## Quick Start

### 1. Add local domains to /etc/hosts

```bash
make hosts
```

This adds the following domains to your `/etc/hosts`:
- `moneycast.local` - Main Laravel application
- `mailpit.moneycast.local` - Email testing UI
- `vite.moneycast.local` - Vite dev server (HMR)

### 2. Start the development environment

```bash
make up
```

### 3. Access the application

- **App**: http://moneycast.local
- **Mailpit**: http://mailpit.moneycast.local
- **Vite**: http://vite.moneycast.local

## Available Commands

### Docker Management

```bash
make up           # Start all services
make down         # Stop all services
make restart      # Restart all services
make ps           # List running services
make logs         # View all logs
make logs-app     # View Laravel app logs
make logs-nginx   # View nginx logs
make logs-vite    # View Vite dev server logs
```

### Building

```bash
make build        # Build services
make rebuild      # Rebuild without cache
```

### Laravel Artisan

Use the `./artisand` script (Docker Artisan) to run artisan commands:

```bash
./artisand migrate                    # Run migrations
./artisand migrate:fresh --seed       # Fresh migrations with seeding
./artisand cache:clear                # Clear cache
./artisand route:list                 # List routes
./artisand tinker                     # Laravel tinker
```

Or use Makefile shortcuts:

```bash
make migrate                      # Run migrations
make migrate-fresh                # Fresh migrations with seeding
make seed                         # Run seeders
make cache-clear                  # Clear all caches
make optimize                     # Optimize the app
```

Custom artisan commands:

```bash
make artisan cmd="your:command"   # Run custom artisan command
```

### Composer

```bash
make composer cmd="install"       # Install dependencies
make composer cmd="require pkg"   # Add package
make composer cmd="dump-autoload" # Regenerate autoload
```

### NPM

```bash
make npm cmd="install"            # Install packages
make npm cmd="run build"          # Build assets
make npm cmd="run dev"            # Dev mode (already running)
```

### Testing

```bash
make test                         # Run all tests
./artisand test                       # Run tests with custom options
./artisand test --filter=UserTest     # Run specific test
```

### Shell Access

```bash
make shell                        # Open shell in app container
docker exec -it moneycast_vite sh # Open shell in Vite container
```

### Cleanup

```bash
make clean                        # Stop and remove all containers, volumes
```

## Services

### Laravel App (`moneycast_app`)
- **Container**: `moneycast_app`
- **Image**: Custom PHP 8.4-FPM Alpine
- **Port**: 9000 (internal)
- **Features**: PHP-FPM, Composer, PostgreSQL client, Redis extension, Xdebug

### Nginx (`moneycast_nginx`)
- **Container**: `moneycast_nginx`
- **Image**: nginx:1.25-alpine
- **Ports**: 80 (HTTP), 443 (HTTPS)
- **Configs**:
  - `app.conf` - Laravel app (moneycast.local)
  - `vite.conf` - Vite proxy (vite.moneycast.local)
  - `mailpit.conf` - Mailpit proxy (mailpit.moneycast.local)

### Vite (`moneycast_vite`)
- **Container**: `moneycast_vite`
- **Image**: node:24-alpine
- **Port**: 5173
- **Features**: Hot Module Replacement (HMR), WebSocket support

### PostgreSQL (`moneycast_postgres`)
- **Container**: `moneycast_postgres`
- **Image**: supabase/postgres:15.1.1.54
- **Port**: 5432
- **Database**: Configured in `.env` (DB_DATABASE)
- **User**: Configured in `.env` (DB_USERNAME)
- **Password**: Auto-generated by `make install`, stored in `.env` (DB_PASSWORD)

### Redis (`moneycast_redis`)
- **Container**: `moneycast_redis`
- **Image**: redis:7-alpine
- **Port**: 6379
- **Usage**: Cache, sessions, queues

### Mailpit (`moneycast_mailpit`)
- **Container**: `moneycast_mailpit`
- **Image**: axllent/mailpit:latest
- **Ports**: 1025 (SMTP), 8025 (UI)
- **UI**: http://mailpit.moneycast.local

### Queue Workers
- **High Priority**: `moneycast_queue_worker_high`
- **Default**: `moneycast_queue_worker`
- Processes background jobs from Redis queues

## Configuration Files

### Docker Compose
- `docker-compose.yml` - Production base configuration
- `docker-compose.dev.yml` - Development overrides

**Usage**:
```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

### Environment
- `.env.dev.example` - Development environment template
- Copy to `.env` and customize as needed

### Nginx
- `docker/nginx/nginx.conf` - Main nginx configuration
- `docker/nginx/conf.d/app.dev.conf` - Laravel app config
- `docker/nginx/conf.d/vite.dev.conf` - Vite proxy with WebSocket
- `docker/nginx/conf.d/mailpit.dev.conf` - Mailpit proxy

### Vite
- `vite.config.ts` - Vite configuration with:
  - CORS for `moneycast.local`
  - HMR via WebSocket through nginx
  - Origin: `http://vite.moneycast.local`

## Troubleshooting

### Services won't start

```bash
make ps                          # Check service status
docker compose -f docker-compose.yml -f docker-compose.dev.yml logs app
```

### Database connection errors

Check PostgreSQL is running and accessible:

```bash
docker exec -it moneycast_postgres psql -U postgres -d moneycast
```

### Vite HMR not working

1. Check Vite container logs: `make logs-vite`
2. Ensure nginx WebSocket proxy is configured
3. Verify `vite.moneycast.local` resolves to `127.0.0.1`

### Permission errors

```bash
docker exec moneycast_app chown -R www-data:www-data /var/www/html/storage
docker exec moneycast_app chmod -R 775 /var/www/html/storage
```

### Clear all caches

```bash
make cache-clear
```

## Development Workflow

1. **Start services**: `make up`
2. **Watch logs**: `make logs-app` (in separate terminal)
3. **Code changes**: Auto-reload via Vite HMR
4. **Database changes**: `./artisand migrate`
5. **Clear cache**: `make cache-clear` (when needed)
6. **Run tests**: `make test`
7. **Stop services**: `make down` (when done)

## Initial Setup (New Clone)

```bash
# Clone repository
git clone <repo-url>
cd MoneyCast

# Add hosts
make hosts

# Copy environment file
cp .env.dev.example .env

# Full installation (builds, starts, installs deps, migrates)
make install

# Access app
open http://moneycast.local
```

## Production Differences

Development environment includes:
- Xdebug for debugging
- Vite dev server with HMR
- Mailpit for email testing
- Volume mounts for live code changes
- Development-only login links

Production uses:
- Optimized PHP (no Xdebug)
- Compiled assets (no Vite)
- Real SMTP server
- Production nginx configs
- SSL/TLS certificates
